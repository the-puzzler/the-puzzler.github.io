# Amortised Assignment Generation draft

This is a deliberately short post scaffold. It keeps the section structure of
`curriculum-mining`, but its styling is intentionally neutral so AAG can have
its own visual direction.

Before publishing:

1. Review the title, subtitle and copy.
2. Put the lead image in `assets/` and replace the image placeholder.
3. Add the post at the top of `posts.json` with its title, date, path, description, social image, and tags.
4. Run `node scripts/build-share-pages.mjs` to generate its social sharing redirect.

Preview before adding it to `posts.json`:

`http://localhost:8000/post.html?p=aag`
